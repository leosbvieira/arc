Aeternum — escritório · decisão tipográfica

Espécime tipográfico

Só tipografia. Oito conjuntos (voz + UI + número), dois deles controles, todos renderizados no mesmo texto e nos mesmos números, nos tamanhos reais do app: voz a 21/27/30px, UI a 11.5–16px, número herói a 40–64px e ponto miúdo a 11.5px. Fundo #080A0D, cards #15191F, texto #F4EFE7 — a cor está quase ausente de propósito. Tamanhos medidos em app/src/theme.ts, Home.tsx e Revisao.tsx. Todas as famílias existem no Google Fonts e têm pacote @expo-google-fonts confirmado.

01 — a prova do problema

Fraunces: o diagnóstico da D3 está certo

A Fraunces tem eixo óptico (opsz 9–144). O app carrega uma instância estática (Fraunces_500Medium): o opsz fica travado no default do eixo (~14, calibrado para texto corrido) e não há API no @expo-google-fonts para movê-lo — o pacote entrega um TTF por peso, sem eixos. Abaixo, a mesma frase em três colunas: como o app a renderiza (opsz fixo), o que o eixo faria (opsz automático, só possível no navegador) e a alternativa. Onde a coluna do app engrossa e perde o desenho, é onde o app a usa: 18–34px (greeting 30, heroTitle 27, metricValue 21, reviewTitle 18, nivel 34).

Leitura: a 18–24px a coluna do app fica com traço grosso e apertado — o "fofa" que o Leo nomeou. A coluna do meio mostra que a Fraunces sabe se resolver nesses tamanhos, mas só via opsz, que o stack Expo não expõe. A 60px as duas Fraunces voltam a brilhar — e o app nunca a usa aí (o maior tamanho real da serifa é 34px, em nivel). Conclusão: não é a fonte errada, é a faixa de tamanho errada para um corte que não podemos ajustar. A saída é uma serifa cujo corte único já nasça certo a 18–34px.

03 — o teste dos números

Figuras tabulares: o dígito dança ou fica na coluna?

O mesmo saldo mudando — 1.240 → 1.305 → 1.190 — empilhado e alinhado à direita. Se os dígitos se alinham verticalmente, a fonte é segura para número que atualiza ao vivo. Em React Native, fontVariant: ["tabular-nums"] funciona no iOS mas é inconsistente no Android — não dá para confiar. Por isso o status pesa: "por construção" (mono) é garantia; "depende de tnum" é risco. Onde o tnum existe, a segunda pilha mostra o que o navegador faz — e o RN Android não garante.

04 — veredito

Recomendação

Conjunto 01 — Instrument Serif + Space Grotesk + IBM Plex Mono

O número fica em IBM Plex Mono: tabular por construção, saldo imóvel ao contar nas duas plataformas, e o +10 miúdo some na linha da tarefa. A voz sai da Fraunces para a Instrument Serif: corte único desenhado já certo para 18–34px (altura-x ~30% maior que a Fraunces no mesmo corpo, contraste contido), e a troca custa exatamente uma família no theme.ts — UI e mono não mudam.

05 — custo da troca

O que muda no código (conjunto 01)

Hoje o app carrega 3 famílias / 6 arquivos (Fraunces 500; Space Grotesk 400/500/600/700; IBM Plex Mono 500). Com a recomendação: 3 famílias / 7 arquivos — sai Fraunces_500Medium, entram InstrumentSerif_400Regular e seu itálico (opcional, para ênfase na voz). Nenhum estilo de tela muda: os apelidos fonts.serif, fonts.ui* e fonts.mono continuam os mesmos.

app/src/theme.ts

// objeto fonts — troca de 1 linha (+1 opcional)
export const fonts = {
  ui: "SpaceGrotesk_500Medium",
  uiSemi: "SpaceGrotesk_600SemiBold",
  uiBold: "SpaceGrotesk_700Bold",
  // era: serif: "Fraunces_500Medium",
  serif: "InstrumentSerif_400Regular",
  serifItalic: "InstrumentSerif_400Regular_Italic", // opcional
  mono: "IBMPlexMono_500Medium",
};

app/App.tsx

// sai:
import { useFonts, Fraunces_500Medium }
  from "@expo-google-fonts/fraunces";

// entra:
import {
  useFonts,
  InstrumentSerif_400Regular,
  InstrumentSerif_400Regular_Italic,
} from "@expo-google-fonts/instrument-serif";

const [fontsLoaded] = useFonts({
  InstrumentSerif_400Regular,
  InstrumentSerif_400Regular_Italic, // opcional
  SpaceGrotesk_400Regular,
  SpaceGrotesk_500Medium,
  SpaceGrotesk_600SemiBold,
  SpaceGrotesk_700Bold,
  IBMPlexMono_500Medium,
});

Heróis: onde hoje metricValue / nivel / reviewPct usam fonts.serif, passam a fonts.mono — é aí que o algarismo-herói ganha o tabular por construção. São 5 estilos em 2 arquivos (Home.tsx, Revisao.tsx), mudança de uma palavra cada. Instalação: npx expo install @expo-google-fonts/instrument-serif e remoção do pacote fraunces.
